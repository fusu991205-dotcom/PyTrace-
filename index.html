📡 接入我的 IDE

在你的解释器、你的目录里照常运行你的代码，PyTrace 只在旁边观测 —— 环境 100% 是你自己的（conda / venv / IDE 配置全都一致），事件实时投到本界面。

方式一 · 命令行运行（推荐，信息最全）
python -m pytrace main.py
在 PyTrace 目录下执行；或先把 PyTrace 目录加进 PYTHONPATH： PYTHONPATH=/path/to/PyTrace python -m pytrace main.py
方式二 · 代码注入（在 IDE 里点运行就行）
import sys; sys.path.insert(0, r"PyTrace 所在目录") import pytrace; pytrace.attach()
加在脚本最前面，之后整个脚本的执行都会被投到这里的舞台。
